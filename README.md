# Simutrans Image Editor (Simutrans テクスチャ乗算合成・ペイントツール Web)

**Simutrans** のアドオン（建物・車両・ストラクチャー等）開発に特化した、ブラウザ完結型のドット絵・テクスチャ合成＆ペイントエディタです。  
インストール不要で、PCおよびタブレット（マルチタッチ・ペン入力対応）のWebブラウザ上で動作します。

- **公開URL (GitHub Pages):** https://cacapo2501.github.io/SimutransImageEditor.github.io/

---

## 主な機能

### 1. ベース画像作成・DEFTILE立体建物ジェネレータ (`EasyBuildingCreator` 互換)
- **新規ベース画像作成 (`#E7FFFF` 背景):** 任意の幅・高さ（`64×64` / `64×96` / `64×128` 等のプリセット対応）で透過背景色 `#E7FFFF` 塗りつぶしのベース画像を即座に作成できます。
- **DEFTILEからの立体建物生成:** グレースケール高さマップ（DEFTILE）からアイソメトリック建物スプライトを自動生成します。
  - フロア数・1フロアのピクセル高さ・天面/南面/東面の色・フロア境界線・滑らか補間のリアルタイム調整
  - 4方向結合（`S / E / N / W`）および単一方向（`Sのみ`）出力対応（最小辺の4倍の倍数サイズへの自動整列）
  - DEFTILE専用のペイント編集モード＆**リアルタイム立体プレビュー小窓**を搭載
- **ベース画像・マスク画像の単体保存:** 編集・自動生成したベース画像とマスク画像を個別にPNGダウンロードできます。

### 2. レイヤーベースのテクスチャ乗算・ストラクチャー合成
- **乗算（テクスチャ）＆ストラクチャー（小物）レイヤー:** 複数レイヤーを重ね合わせ、不透明度や表示順序を自由に管理できます。
- **3種類の変形モード＆全域タイリング:**
  - 矩形リサイズ（軸平行） / 自由3頂点（平行四辺形・アイソメトリック壁面用） / 自由4頂点（透視投影）
  - 縦横の繰り返し倍率（タイル）指定、全域マッピング、1px単位のピクセルスナップに対応
- **相対参照コピー:** 元レイヤーの画像や設定を共有したまま配置座標だけを複製できます。
- **マスクカラー範囲指定＆除外オプション:**
  - 特定のマスク色の範囲にのみレイヤーを適用、または**「指定したマスク色を除外（この色の範囲には重ねない）」**反転適用が可能
  - ストラクチャー内の `#E7FFFF` 背景を自動透過するオプションを搭載

### 3. トーン・ハイライト・マスク乗算 (Tint)・半透明制御
- **マスク色別の個別トーン調整:** 全体またはマスク色ごとに「最も暗い色（デフォルト `#000018`）」「最小/最大の明るさ %」「ハイライト Normalブレンド」を設定できます。
- **マスクカラー乗算 (Tint):** マスク色ごとに任意のカラーを乗算し、屋根や壁面の色バリエーションを非破壊で作成できます。
- **マスク色域別の出力アルファ（半透明）設定:** ガラス窓や半透明表現のために、最終出力ピクセルの不透明度をマスク色ごとに `0%〜100%` で指定できます。
- **SpecialColor保護ぼかし:** 特殊色や背景色を除外したまま画像全体にガウスぼかしを適用できます。

### 4. Simutrans 特殊色 (`SpecialColor`) 完全保護＆窓色ランダム暗転
- **背景色 `#E7FFFF` ＆ 特殊色の厳密保護:**
  - `special_colors.csv`（夜間発光色・プレイヤーカラー等）の自動読み込み・手動インポートに対応
  - ベース画像固有の特殊色や `#E7FFFF` 背景は編集・ぼかし・半透明化の影響を受けず完全に保護されます
  - 乗算や色調整によって**偶然 SpecialColor や `#E7FFFF` と重複してしまった一般ピクセル**は、PNG書き出し時に R成分を自動補正（`±1`）して誤発光・誤透過を防止します
- **窓色ランダム暗転 (`RamdomWindowDarken` 互換):**
  - 4近傍で連結した夜間発光窓（`#57656F` / `#4D4D4D`、または全SpecialColor）をブロック単位で検出し、指定した暗転比率（`0〜100%`）でランダムに消灯（SpecialColor解除）できます。

### 5. ドット絵特化ペイントエディタ
- **描画・選択ツール:**
  - ドットブラシ / 連続直線 / 矩形塗りつぶし / バケツ塗りつぶし / スポイト / テキスト挿入 / 複数色一括置換
  - 矩形選択 / 多角形選択 / 自動選択（Magic Wand） / 同色選択
  - 選択範囲の演算モード（**新規 / ＋追加 / －一部削除 / ×乗算**）
- **ビル・連続階向け「🔁 上方リピート」機能:**
  - 選択範囲内を描画・塗りつぶし・色置換・反転・貼付すると、選択範囲外の上方へ「指定px間隔 × 指定回数」だけ同じ編集を同時反復します。
- **オニオンスキン（外部画像位置目安）:**
  - 複数の外部画像を半透明で重ね、1px単位の位置ずらしや `#E7FFFF` 透過を行いながら作画の目安にできます（保存時には自動破棄され出力されません）。
- **ピクセルパーフェクト補助線＆Simutransタイル菱形ガイド:**
  - 任意のpx間隔の直交補助線（色変更可）
  - 画像左下 `(0, height)` を基準とし、上下端4px・実効高さ `Th - 1` のSimutrans標準アイソメトリックタイル敷き詰めガイド（メイン編集画面でも表示可能）
- **画像サイズ変更（マスク連動）＆コピー＆ペースト:**
  - ベース画像のキャンバス拡張・切抜・拡大縮小に合わせてマスク画像も自動連動リサイズ
  - 選択範囲のコピー＆ペースト（矢印キー1px移動）、外部画像の取り込み貼り付け、上下/左右反転に対応

### 6. プロジェクト保存・外部連携
- **プロジェクトファイル (`.proj.json`) 保存・復元:** ベース画像・マスク画像・全レイヤー画像・トーン/Tint設定・カスタムパレット・キーバインドを1つのJSONファイルに内包して保存・再開できます。
- **Google Drive / ローカルフォルダ連携:** ローカルフォルダ一括読込や、Google Drive Picker 経由でのファイル読込に対応しています。

## 基本的な使い方

1. **画像の用意**
   - 「ベースPNGを開く」、または「🆕 新規作成 (#E7FFFF)」「🏗️ DEFTILEから生成」からベース画像を用意します。
   - マスク画像が未読込の場合、ベース画像のグレースケール階調からマスク画像が自動生成されます（SpecialColorや有彩色はベース色がそのまま引き継がれます）。
2. **ベース・マスクのペイント編集**
   - 「✏️ ベース画像を編集」「🎭 マスク画像を編集」からドット単位の編集や領域分けを行います。
3. **テクスチャ・ストラクチャーの配置**
   - 「＋ 乗算追加」「＋ 小物追加」で画像を読み込み、キャンバス上の頂点ハンドルをドラッグして配置・変形します。
   - 必要に応じて「適用マスクカラー設定」で適用するマスク色（または除外するマスク色）を指定します。
4. **トーン・色調・窓暗転の調整＆PNG出力**
   - 「トーン＆ハイライトブレンド」「マスクカラー乗算 (Tint)」「窓色ランダム暗転」で質感を調整し、画面左下の **「合成結果をPNG保存」** から出力します。

## ショートカットキー（ペイントエディタ内）

| 操作 | ショートカット |
| :--- | :--- |
| ドットブラシ | `B` |
| 直線 | `L` |
| 矩形塗りつぶし | `R` |
| 塗りつぶし (バケツ) | `G` |
| スポイト | `I` |
| 矩形選択 | `M` |
| 多角形選択 | `P`（始点クリック / ダブルクリック / `Enter` で確定） |
| 自動選択 (Magic Wand) | `W` |
| 同色選択 | `C` |
| テキスト挿入 | `T` |
| コピー / 貼り付け | `Ctrl + C` / `Ctrl + V` |
| 元に戻す / やり直し | `Ctrl + Z` / `Ctrl + Y`（または `Ctrl + Shift + Z`） |
| 選択解除 / 操作キャンセル | `Esc` または `Ctrl + D` |
| 貼り付け位置の1px微調整 | `↑` `↓` `←` `→`（`Enter` で確定） |

※各ツールのキーバインドはペイントエディタ上部の「⌨️ キー設定」から自由に変更できます。

## ファイル構成

保守性を高めるため、全ソースファイルを機能別モジュール（各ファイル400行未満）に分割して構成しています。

```text
├── index.html                  # エントリHTML
├── style.css                   # スタイルシートエントリ
├── special_colors.csv          # Simutrans 特殊色定義CSV（任意配置）
├── css/
│   ├── base.css                # 基本レイアウト・サイドバー・フォーム
│   ├── sidebar-widgets.css     # レイヤーリスト・Tintテーブル・メインキャンバス
│   ├── paint-editor.css        # ペイントエディタ画面UI
│   ├── modals.css              # 各種ダイアログ・カラーピッカーUI
│   └── deftile-builder.css     # DEFTILEビルダー＆ライブプレビューUI
└── js/
    ├── app.js                  # メインアプリケーション統括
    ├── color-utils.js          # 色空間変換・CSVパース・SpecialColor衝突回避
    ├── color-picker.js         # HSV / RGB カラーピッカー
    ├── transform.js            # 射影変換・アフィン変換・保護ぼかし処理
    ├── layer.js                # レイヤーデータモデル・タイリング・マスク判定
    ├── layer-manager.js        # レイヤー一覧UI・操作制御
    ├── render-engine.js        # 合成レンダリングパイプライン
    ├── window-darken.js        # 窓色ランダム暗転（連結成分検出・SpecialColor解除）
    ├── mask-generator.js       # ベース/マスク解析・マスク自動生成
    ├── tone-tint-controller.js # トーン・ハイライト・半透明・Tint制御
    ├── canvas-controller.js    # メインキャンバスのパン・ズーム・頂点ハンドル操作
    ├── palette-manager.js      # パレット生成・画像スポイト安全読込

    ├── paint-clipboard.js      # 選択演算・コピー＆ペースト・外部画像貼付
    ├── paint-flip.js           # フローティング/選択範囲/全体の上下・左右反転
    ├── paint-repeat.js         # 選択範囲の上方リピート反復描画
```
